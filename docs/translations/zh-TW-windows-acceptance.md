# Windows 11 繁體中文人工驗收

本方案只準備本機驗收，不合併 PR，也不部署網站。來源限定為
`frank-jd-wilson/gods-eye-view` 的 `feature/zh-tw-localization` 分支；
[Draft PR #2](https://github.com/frank-jd-wilson/gods-eye-view/pull/2) 的目標為 `main`。

## 下載與雙擊

1. 下載 [start-zh-tw-acceptance.bat 原始檔](https://raw.githubusercontent.com/frank-jd-wilson/gods-eye-view/feature/zh-tw-localization/scripts/windows/start-zh-tw-acceptance.bat)，另存到「下載」或桌面。確認檔名是 **`start-zh-tw-acceptance.bat`**，不是 `.bat.txt`，也不要將 GitHub HTML 頁面另存成 bat。可先用記事本檢視內容。
2. 雙擊執行，不需要系統管理員權限。預設目錄為 **`F:\Digital Twin\gods-eye-view`**，包含空白的路徑已加引號。不要預先建立該目標資料夾；Git 會建立目標及缺少的上層目錄。
3. 腳本先檢查 PATH 中的 `node.exe`、`npm.cmd`、`git.exe`，Node 必須為 **24.x 且至少 24.14.0，或 26.x**，與專案 `engines.node` 一致。缺少工具時會停止並提供官方下載網址，不自動安裝 Node 或 Git；安裝時保留 npm 與 PATH 選項，完成後重新雙擊。
4. 首次執行只 clone 自己的 Fork 與 zh-TW 分支，再用 `npm.cmd ci` 安裝 lockfile 中的套件。需連線 GitHub、npm 與套件必要下載來源；這是 Windows 自身的網路，Codex Cloud 允許網域設定不會自動套用到電腦。
5. 安裝完成會使用真正的專案啟動命令：`npm.cmd run dev -- --host 127.0.0.1 --port 4175 --strictPort --open "/?lang=zh-TW"`。不是 `npm start`。Vite 會嘗試開啟預設瀏覽器。
6. 視窗顯示 Vite ready 後，在 **Firefox 或 Edge** 的網址列貼上 **<http://127.0.0.1:4175/?lang=zh-TW>**。自動開啟失敗不代表伺服器失敗，直接貼上網址即可。終端視窗須保持開啟；停止時按 `Ctrl+C`，若詢問終止批次工作，輸入 `Y`。

腳本輸出使用英文 ASCII，避免 Windows 主控台亂碼；操作說明與 App 為繁體中文。

## 保護既有安裝與重複啟動

- 不修改、刪除或接管 Pinokio 安裝，也不修改防火牆、PowerShell ExecutionPolicy、憑證或其他系統安全性設定。全程使用 `npm.cmd`，不呼叫 `npm.ps1`。
- 目標已存在時，只接受本腳本先前建立且有 Git 本機標記 `gev.zhTwAcceptance=true` 的 checkout；其他目錄直接停止。不要為既有 Pinokio 目錄手動加入標記。若目標被占用，保留原目錄，改用另一個尚不存在的獨立目錄，於腳本副本修改 `GEV_DIR`。
- 每次啟動核對 origin 與分支，有未提交／未追蹤檔案或本機額外提交便停止。僅允許 fetch 後 fast-forward，不切換其他分支、不 reset、不 clean、不 stash。Git 忽略的個人 `.env` 不會被刪除，也不會被腳本上傳；既有環境設定可能影響 App，請自行確認。
- `node_modules` 內記錄 lockfile 與 Node 版本的雜湊。相同時略過重裝；變更時 `npm ci` 重建這個獨立 checkout 的 `node_modules`，不碰其他安裝。若套件遭手動破壞而標記未變，可只刪除這個 checkout 的 `node_modules/.gev-zh-tw-install` 後重試。
- 設定 `PUPPETEER_SKIP_DOWNLOAD=true` 只略過自動化測試用 Chromium 下載，不影響 Firefox／Edge 使用 App；本腳本不執行瀏覽器自動化測試。
- 專用連接埠為 **4175**，不同於專案常用 4173；若被占用，Vite 會停止，不會終止其他程式，也不會偷偷改用另一個網址。先停止先前啟動的驗收視窗再重試。
- 基本地圖及介面驗收不需要新增 API 金鑰。金鑰、付費功能與實體 SDR 裝置不在本次必要驗收範圍。不需要貼上 Token 或密碼，也不要把 `.env` 加入提交。
- 若 Windows 或組織政策阻擋腳本，保留錯誤訊息並依組織規範處理；不要停用保護或更改執行政策。

## 人工驗收清單

請在 Firefox 與 Edge 分別執行，記錄 Windows、瀏覽器版本、終端顯示的完整 Commit、顯示縮放比例與瀏覽器縮放比例。逐項填寫「通過／失敗／未測」，不要把未測算成通過。

| 項目            | 操作與預期結果                                                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 啟動及首頁      | Vite ready；首頁、基本地圖可操作。首次畫面出現「選擇初始視角」「即時目標」「手動探索」。資料尚未返回與翻譯缺陷分開記錄。                                                                                           |
| 原生語言選單    | 用實體滑鼠開啟語言選單，選擇 English，再選「繁體中文（台灣）」。每次可正常開啟、選取、關閉，畫面隨切換重新載入，其他語言仍可選。                                                                                   |
| 偏好保存        | 選單選擇繁體後，開啟**不含 `?lang=`** 的 <http://127.0.0.1:4175/>，按 F5、Ctrl+F5，關閉分頁再重新開啟，均維持繁體。不要只用帶繁體參數的網址驗證保存。無痕／封鎖儲存模式另行記錄。                                  |
| 網址與 fallback | `/?lang=zh-Hant` 顯示台灣繁體；`/?lang=zh-CN` 顯示既有簡體且不覆寫選單儲存偏好。未支援語系會繼續嘗試已存偏好、瀏覽器語言，最後英文，並非一律立即英文。缺漏翻譯的英文 fallback 已有單元測試，不需為驗收修改翻譯檔。 |
| 視窗尺寸與重載  | 最大化→還原→窄視窗→最大化；每一步用滑鼠切換中英文並重新整理。確認選單無遮擋、可點擊且不卡住。特別記錄此前自動化未穩定通過的尺寸改變＋重載組合。                                                                    |
| 縮放及長文字    | 瀏覽器 100%、125%、150%、200%，並記錄 Windows 125%／150% 顯示縮放；檢查設定、圖層、提示與錯誤長句。文字可讀、可捲動，按鈕不互相遮住；刻意省略文字須有可取得完整內容的方式。檢查繁體字體缺字、亂碼與不合理截斷。    |
| 設定及主要控制  | 檢查「設定」「資料圖層」「地圖來源」「載入」「儲存金鑰」等文字與提示；不需要輸入或儲存金鑰。                                                                                                                       |
| 航空            | 檢查飛機／軍機、航向、航跡、高度、速度等實際顯示用語與上下文；保留 ADS-B、呼號、單位等代碼，標記不自然或錯誤術語。                                                                                                 |
| 海事            | 檢查船舶、航速、航向、AIS 與船舶詳細面板；區分原始船名／服務資料與固定 UI 翻譯。                                                                                                                                   |

| 氣象            | 檢查天氣／氣象相關圖層、提示、時間、風速、氣壓及單位，確認語意符合台灣使用習慣；不強制啟用需金鑰來源。                                                                                                             |

## 問題回報與驗證限制

失敗請記錄：完整 Commit、瀏覽器版本、起始網址、選擇語系、操作順序、視窗尺寸／縮放、預期與實際結果。附上不含金鑰的畫面或 Console 錯誤；外部來源 HTTP 失敗與介面翻譯問題分開記錄。

Codex 先前的 DOM click 通過只驗證事件與狀態，不代表原生輸入完全通過。獨立 Chromium 滑鼠切換曾通過；組合式尺寸改變／重載原生輸入仍待上述 Windows 驗收。本腳本在 Linux Codex 環境製作，**尚未於 Windows 11 的 cmd.exe 真正雙擊執行**；文件／命令核對與雲端 App 檢查不能取代 Windows 實機結果。
